Context & references

Explanation and version caveats

  • Q16: an after-save flow that updates itself does not automatically stop on the next update. The repaired example is explicitly create-only and reaches 2.
  • Q72: Apex identifiers are case-insensitive, and addError in an after trigger can reject the triggering DML. Either duplicate option remains accepted.
  • Q9: OrgLimits is a real class, but Limits is the transaction governor-usage API.
  • Q43/Q78/Q201: partial success returns row errors; it is not error-free execution or an independent commit outside the transaction.
  • Q58/Q139: junction access depends on both masters and both relationship Sharing Settings.
  • Q92: cascade-deleted children do not run their own delete triggers. The repaired choice asks about explicit DML deletion.
  • Q100: StandardSetController has a 10,000-record ceiling. The repaired scenario is within that ceiling.
  • Q102/Q117/Q189: API 67.0+ security defaults differ from legacy Apex. Q102 is now unscored because the source omitted the necessary version/caller context; Q117/Q189 retain explicit assumptions. Inherited sharing is not invalid for LWC entry points.
  • Q113/Q122: distinguish a direct listener on a component host from ancestor bubbling and shadow-boundary propagation.
  • Q5/Q101/Q173: ordinary org-wide coverage and RunSpecifiedTests per-component coverage are different rules.
  • Q153: Flow debugging does not always roll back; rollback mode and flow type matter. Schedule-triggered debugging can run for one record.
  • Q149: Ant still has legacy deployment capability but has been retired since Spring 2024.
  • Q191: third-party web components are supported; their existence must not be used as an invalid distractor.
  • Q199: SOSL supports middle/trailing wildcards, not the original leading wildcard. Lowercase keywords are not the defect in the flat-list distractor.
  • Q157/Q200: static-Boolean recursion guards and claims about trigger ordering need care; different events are not multiple triggers on the same event.
